Project Documentation
Overview

This application is the final project submission for Problem Statement No. 38 of the Edunet Foundation IBM SkillsBuild Training. It implements a fully automated, production-grade multi-agent AI pipeline for medical insurance claim denial review and appeal drafting.

Architecture

The system follows a strict sequential three-agent pattern inspired by IBM watsonx Orchestrate skill chaining:

1
PolicyAuditAgent — maps the denial code to its governing policy rule (ACC-901, ORTHO-404, or ONCO-202) and extracts the mandatory coverage criteria.
2
ClinicalEvidenceAgent — performs deterministic rule-based NLP on the patient's free-text clinical notes, checking EKG abnormalities, formal PT duration, or companion diagnostic results depending on the denial code.
3
AppealStrategyAgent — issues a final disposition: SUCCESS_PROBABLE (90%+) with a ready-to-file formal appeal letter, or DENIAL_UPHELD with a manual-review notice listing the deficiencies.

Three-Agent Architecture
Agent 1 — PolicyAuditAgent

Input: Denial_Code string (e.g. ERR-ORTHO)
Action: Queries the POLICY_REGISTRY dictionary and extracts the relevant section from insurance_policies.txt.
Output: rule_id, title, criteria, raw_excerpt

Agent 2 — ClinicalEvidenceAgent

Input: Denial_Code + Clinical_Notes free text
Action: Deterministic rule-based NLP using compiled regex pattern lists — no LLM, fully auditable and HIPAA-friendly.

Denial CodeEvidence Logic
ERR-CARDIACChecks for abnormal EKG signals (ST changes, LVH, sinus bradycardia, T-wave inversions) AND atypical chest pain. Clean EKG explicitly disqualifies.
ERR-ORTHOExtracts numeric month count; checks for formal PT / injection keywords; penalises informal activities (yoga, acupuncture, home stretches). Requires ≥ 4 months.
ERR-ONCOLOGYScans for positive companion diagnostic signals (PD-L1 %, HER2+, KRAS wild-type, etc.) and flags negative signals (HER2-negative, KRAS-mutated).

Output: criteria_met (bool), confidence (HIGH/MEDIUM/LOW), rationale

Agent 3 — AppealStrategyAgent

Input: Patient record + Agent 1 output + Agent 2 output
Logic: If criteria_met == True → generates a legally-structured formal appeal letter and tags the case SUCCESS_PROBABLE (90%+). Otherwise → issues a manual-review disposition notice listing deficiencies.
Output: disposition, appeal_text

Policy Rules Reference
ACC-901 — Advanced Cardiac Diagnostic Imaging

Denial Code: ERR-CARDIAC

Coverage requires ALL of:

  • Documented atypical chest pain by a licensed cardiologist or attending physician.
  • A resting EKG within 90 days showing one or more abnormal findings — ST-segment changes, T-wave inversion, LVH, bundle branch block, sinus bradycardia, or other conduction defects.

Non-coverage triggers: Normal resting EKG · Typical (musculoskeletal) chest pain · No prior EKG on file.

ORTHO-404 — Arthroscopic Surgical Procedures

Denial Code: ERR-ORTHO

Coverage requires ALL of:

  • Minimum 4 consecutive calendar months of formally documented conservative therapy.
  • Therapy must be clinically supervised — licensed physiotherapist PT sessions or physician-administered intra-articular injections.
  • Home exercises, yoga, acupuncture, and OTC NSAIDs do not qualify.
  • Imaging confirmation of structural pathology consistent with the proposed surgery.

Non-coverage triggers: < 4 months PT · Documentation gaps · Informal-only remedies.

ONCO-202 — Targeted Oncology & Immunotherapy

Denial Code: ERR-ONCOLOGY

Coverage requires ALL of:

  • A companion diagnostic genetic test (NGS, FISH, IHC, or PCR) on a tumour biopsy sample.
  • Test result must confirm the specific biomarker for the requested agent — e.g., PD-L1 ≥ 1% for Pembrolizumab; HER2-positive (IHC 3+ or FISH ≥ 2.0) for Trastuzumab; KRAS/NRAS wild-type for Cetuximab.
  • Treatment plan co-signed by a board-certified medical oncologist, consistent with NCCN Category 1/2A guidelines.

Non-coverage triggers: No companion diagnostic · Negative/absent required biomarker · Off-label use without Tumour Board support.
